OpenVINO GPU Vulkan Runtime Third Party Programs File

This file collects upstream license texts and notices for the validated Vulkan
runtime dependencies. These components retain their separate license terms.
CLSPV incorporates LLVM/Clang, libclc and SPIR-V infrastructure; the GPU plugin
also links SPIRV-Tools. The corresponding source revisions are listed below.

This file does not imply that every optional component of those projects is
linked. If dependency revisions or build options change, review the resulting
package and update its notices. Slang is a host build tool, not a runtime
dependency. The Vulkan loader, MoltenVK and hardware drivers are supplied
separately; this file does not replace their distribution notices.
